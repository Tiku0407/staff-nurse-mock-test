# स्टाफ नर्स लाइव मॉक टेस्ट (छत्तीसगढ़)

छत्तीसगढ़ स्टाफ नर्स भर्ती परीक्षा के सिलेबस (संचालनालय स्वास्थ्य सेवाएं, 100 अंक, 5 खंड × 20 अंक) पर आधारित CBT शैली का दैनिक मॉक टेस्ट।

## विशेषताएँ

- अभ्यर्थी का नाम और 10 अंकों का मोबाइल नंबर (6–9 से शुरू) अनिवार्य; इनके बिना परीक्षा शुरू नहीं होती, और ये परिणाम पर दिखते हैं
- एक बार में एक प्रश्न, खंड-टैब और प्रश्न-पैलेट (नहीं देखा / उत्तर नहीं / उत्तर दिया / मार्क / उत्तर + मार्क)
- "सेव करें और आगे बढ़ें", "रिव्यू हेतु मार्क करें", "उत्तर हटाएँ", "पिछला"
- 60 मिनट का टाइमर; अंतिम 5 मिनट में लाल चेतावनी; समय पूरा होने पर स्वतः जमा
- पेज रिफ्रेश होने पर भी परीक्षा वहीं से जारी (ब्राउज़र localStorage)
- परिणाम: कुल स्कोर, सटीकता, खंड-वार प्रदर्शन, और प्रत्येक प्रश्न की व्याख्या (सही / गलत / छोड़े फ़िल्टर)
- मोबाइल पर पैलेट नीचे से खुलता है; डार्क मोड और प्रिंट/PDF समर्थन
- परीक्षा जमा होने पर नाम, मोबाइल, स्कोर, खंड-वार अंक और हर प्रश्न का उत्तर (✓/✗) Google Sheet में एक पंक्ति के रूप में सहेजा जाता है — `config.js` में Apps Script Web app URL लिखें; विधि `sheet/Code.gs` में
- कोई सर्वर या बिल्ड नहीं — केवल एक `index.html` फ़ाइल

## GitHub Pages पर लाइव करना

1. Repository → **Settings** → **Pages**
2. **Source:** Deploy from a branch → **Branch:** `main` / `(root)` → **Save**
3. 1–2 मिनट बाद टेस्ट यहाँ खुलेगा: `https://<आपका-username>.github.io/staff-nurse-mock-test/`

## रोज़ नया सेट

- हर सुबह लगभग 8:00 बजे (IST) एक नया 50-प्रश्न सेट अपने आप बनकर जुड़ता है; वेबसाइट सबसे नया सेट खोलती है और पुराने सेट ड्रॉपडाउन से चुने जा सकते हैं (`?set=NN` लिंक भी चलता है)।
- सेट-क्रमांक तारीख से चलता है: सेट 01 = 22 अक्टूबर 2026, सेट 02 = 23 अक्टूबर 2026, …
- हर खंड का फ़ोकस विषय रोज़ बदलता है, कठिनाई धीरे-धीरे बढ़ती है, और पिछले सेटों से दोहराव की जाँच होती है — पूरी विधि `tools/DAILY_SET.md` में।

## फ़ाइलें

| फ़ाइल | काम |
| --- | --- |
| `index.html` | पूरा CBT टेस्ट पेज (एक ही रहता है) |
| `sets/manifest.js` | सभी सेटों की सूची |
| `sets/set-NN.js` | एक दिन के 50 प्रश्न, उत्तर व व्याख्या |
| `tools/DAILY_SET.md` | रोज़ का सेट बनाने की विधि |
| `tools/validate.js` | ढाँचा, कठिनाई, उत्तर-वितरण और दोहराव की जाँच |
| `tools/add_set.js` | नया सेट manifest में जोड़ना |
| `tools/smoke_test.js` | ब्राउज़र में पूरा टेस्ट चलाकर जाँच |

हाथ से नया सेट जोड़ना हो: `sets/set-NN.js` बनाएँ, फिर `node tools/add_set.js NN` और `node tools/smoke_test.js NN` चलाएँ।
